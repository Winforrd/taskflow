# TaskFlow 在线协同任务管理平台

> 基于 Spring Boot + Vue3 构建的在线协同任务管理平台，面向团队项目协作场景，实现团队空间、项目管理、任务生命周期管理、权限控制以及实时消息通知等功能。

---

# 项目介绍

TaskFlow 是一个面向团队协作场景设计的任务管理平台。

系统围绕：

- 用户
- 团队
- 项目
- 任务

四个核心业务对象，实现团队成员协作、任务分配、进度跟踪以及实时消息同步。


针对团队协作过程中存在的：

- 任务信息分散
- 项目进度不可视
- 成员沟通效率低
- 任务状态管理混乱
- 消息反馈不及时

等问题，设计并实现了一套完整的在线协同任务管理系统。


系统采用前后端分离架构：

- 后端基于 Spring Boot 构建业务服务；
- 使用 RBAC 模型实现权限控制；
- 使用任务状态机保证业务流程一致性；
- 使用 WebSocket 实现实时消息推送；
- 使用 Redis 优化高频数据访问。


---

# 项目亮点

- 基于状态机实现任务生命周期管理，统一控制任务状态流转；
- 基于 WebSocket 实现任务通知、评论提醒等实时消息推送；
- 基于 RBAC 模型实现用户、团队、项目多层权限控制；
- 基于 Redis 缓存优化未读消息等高频访问数据；
- 基于 AOP 实现系统操作日志自动记录；
- 基于 Spring Scheduler 实现任务截止时间提醒。

# 核心功能


## 1. 用户认证

实现完整用户体系：

- 用户注册
- 用户登录
- Token认证
- 用户信息管理


---

## 2. 团队空间管理

支持团队协作管理：

- 创建团队
- 加入团队
- 团队成员管理
- 成员移除
- 团队角色管理


团队角色：

|角色|说明|
|-|-|
|Owner|团队所有者|
|Admin|团队管理员|
|Member|普通成员|


---

## 3. 项目管理

支持项目生命周期管理：

- 创建项目
- 修改项目
- 删除项目
- 项目成员管理
- 项目负责人设置
- 项目权限控制


---

## 4. 任务管理

实现任务完整生命周期。


支持：

- 创建任务
- 编辑任务
- 删除任务
- 任务负责人指派
- 设置截止时间
- 添加评论
- 查看任务动态
- 查看任务历史记录


---

## 5. 基于状态机的任务流转


针对任务生命周期设计状态机模型。


任务状态：

```
TODO

 ↓

DOING

 ↓

DONE
```


后端统一维护状态转换规则：

- 校验当前任务状态；
- 判断目标状态是否合法；
- 记录状态变化。


避免前端绕过业务规则直接修改任务状态。


---

## 6. WebSocket实时通知


基于 WebSocket 建立客户端与服务器长连接。


支持：

- 任务指派通知；
- 评论提醒；
- 系统消息；
- 截止时间提醒。


消息流程：

```
用户操作

    ↓

业务事件产生

    ↓

生成通知记录

    ↓

WebSocket推送

    ↓

客户端实时展示
```


相比传统轮询方式，提高消息实时性并减少无效请求。


---

## 7. 截止时间提醒


基于 Spring Scheduler 实现定时任务。


功能：

- 周期扫描任务截止时间；
- 自动生成提醒消息；
- 推送用户通知。


---

## 8. 数据统计


提供项目数据统计能力：

- 项目任务数量统计；
- 任务完成情况统计；
- 成员任务分布；
- 项目进度分析。


---

## 9. 操作日志


基于 AOP 实现统一操作记录。


记录：

- 操作用户；
- 请求接口；
- 操作时间；
- 操作结果。


用于问题追踪和系统审计。

# 技术难点与解决方案


## 1. 任务状态一致性


### 问题

任务状态如果由前端直接修改，容易产生非法状态。


### 解决方案

设计任务状态机：

```
状态枚举

+

状态转换规则

+

后端统一校验
```


保证任务生命周期符合业务规则。


---

## 2. 实时消息推送


### 问题

HTTP请求模式无法满足实时通知需求。


### 解决方案

引入 WebSocket：

- 建立长连接；
- 服务端主动推送；
- 降低轮询压力。


---

## 3. 权限数据隔离


### 问题

不同团队、不同项目之间需要保证数据访问边界。


### 解决方案

通过：

- 用户身份认证；
- 团队角色校验；
- 项目成员权限校验；

实现数据隔离。
